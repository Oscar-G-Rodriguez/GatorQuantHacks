# H21 staged stock readout

This is a delivery protocol for the existing declared comparisons, recorded before inspecting amended confidence results. It adds no model, target, search variant, strategy or trade. The report remains development evidence with prior adaptive exposure, a retrospective static universe and an assumed availability clock.

Join amended inference to the complete frozen stock comparison table by exact comparison ID and block length. Every existing row and evidence status stays visible. For each of119 taxonomy categories, preserve its definition and coverage fields and add counts of measured conditional forecast cells, cells with eligible uncertainty at both block lengths, positive point-estimate cells, and positive cells with both Romano–Wolf adjusted p-values at or below0.05. These are overlapping cell counts, never independent discoveries or a category-level test. Raw response means stay descriptive. Record missing uncertainty and unsupported resamples explicitly.

Retain all broad-panel forecast comparisons separately. For labels/patterns/text forecasts, tabulate every pattern/outcome/horizon/delay/group across2023,2024,2025, including unsupported years. Describe a cross-year pattern as consistently positive only when all three years have measured positive paired loss improvements; describe it as passing both declared adjustments across years only when all three also have eligible uncertainty and p<=0.05 at both block lengths. A passing cell or pattern still needs full-search placebo evidence, option-priced comparisons where relevant, an economic mechanism, feasible execution and genuinely unseen confirmation. No result is called alpha. No thresholds or settings are changed after viewing the readout.

All joins and numerical summaries run in a scheduled allocation. The immutable inputs are the parent stock manifest, verified report receipt and amended uncertainty-stage manifest/receipt. Save the complete joined comparison CSV, enriched119-row master, broad-panel table, cross-year forecast table, plain-language Markdown, exact output hashes and actual scheduler evidence. Return this small report stage before the larger draw archive if necessary, labeling that transfer separately. Keep options and499 full-search placebo stages explicitly pending; a partial report does not meet final atlas acceptance.
