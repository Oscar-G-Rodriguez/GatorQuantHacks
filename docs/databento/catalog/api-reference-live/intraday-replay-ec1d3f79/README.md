# Intraday replay

Provide replay start before beginning the session and respect the documented retention window. Live replay filters exchange-event time except BBO/CBBO, which use receipt time.

Official route: [Databento documentation](https://databento.com/docs/api-reference-live/basics/intraday-replay).

Review state: `retrieved`.
