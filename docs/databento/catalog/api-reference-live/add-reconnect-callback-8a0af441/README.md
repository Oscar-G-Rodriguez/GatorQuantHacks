# Live.add_reconnect_callback

Observe reconnection boundaries and rebuild/replay dependent state as required. A reconnect callback does not prove that no records were missed.

Official route: [Databento documentation](https://databento.com/docs/api-reference-live/client/add-reconnect-callback).

Review state: `retrieved`.
