# Errors

Classify authentication, entitlement/payment, invalid input, partial resolution, rate-limit and transient server failures. Retry only recoverable cases; never replace failures with an apparently complete empty dataset.

Official route: [Databento documentation](https://databento.com/docs/api-reference-live/basics/errors).

Review state: `retrieved`.

Implementation route: [task guide](../../../live/README.md). Return to [catalog](../../README.md).
