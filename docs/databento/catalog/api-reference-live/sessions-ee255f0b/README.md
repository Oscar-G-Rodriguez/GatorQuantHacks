# Sessions

Keep all subscriptions within the session’s dataset. Process acknowledgments/control messages and explicitly close the session; a connected socket does not prove every symbol subscribed successfully.

Official route: [Databento documentation](https://databento.com/docs/api-reference-live/basics/sessions).

Review state: `retrieved`.

Implementation route: [task guide](../../../live/README.md). Return to [catalog](../../README.md).
