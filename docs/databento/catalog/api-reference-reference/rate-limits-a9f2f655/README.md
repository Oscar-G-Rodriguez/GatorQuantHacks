# Rate limits

Bound per-method concurrency and honor Retry-After. Limits apply across requests sharing an IP and differ by service; a cluster may share an aggregate request budget.

Official route: [Databento documentation](https://databento.com/docs/api-reference-reference/basics/rate-limits).
