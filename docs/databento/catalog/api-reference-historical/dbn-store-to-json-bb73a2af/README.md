# DBNStore.to_json

Export records with explicit formatting and mapping. Parse 64-bit string values directly to integers, not through float.

Official route: [Databento documentation](https://databento.com/docs/api-reference-historical/helpers/dbn-store-to-json).

Review state: `retrieved`.

## Python parameter inventory

Required: `path`.
Optional: `pretty_ts`, `pretty_px`, `map_symbols`, `compression`, `schema`, `mode`.

Read the source for types, defaults, return values, and incompatible combinations.
