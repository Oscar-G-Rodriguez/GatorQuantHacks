# DBNStore.to_csv

Export a selected schema with explicit price/time formatting and symbol mapping. Preserve full integer precision on re-import.

Official route: [Databento documentation](https://databento.com/docs/api-reference-historical/helpers/dbn-store-to-csv).

Review state: `retrieved`.

## Python parameter inventory

Required: `path`.
Optional: `pretty_ts`, `pretty_px`, `map_symbols`, `compression`, `schema`, `mode`.
