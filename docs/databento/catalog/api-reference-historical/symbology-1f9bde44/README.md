# Symbology

Select the service-specific symbol type and retain dated mappings. Market-data and Reference identifiers have different supported combinations; a timeless ticker lookup is insufficient.

Official route: [Databento documentation](https://databento.com/docs/api-reference-historical/basics/symbology).

Review state: `retrieved`.
