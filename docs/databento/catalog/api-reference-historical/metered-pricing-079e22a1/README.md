# Metered pricing

Historical usage is metered on uncompressed binary bytes. Repeated streaming downloads can be billed again; retain approved raw data or a known reusable batch job.

Official route: [Databento documentation](https://databento.com/docs/api-reference-historical/basics/metered-pricing).
