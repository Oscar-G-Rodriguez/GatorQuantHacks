## Limits and discrepancies

The website serves whole chapters for many section routes. Page cards address the matched section; chapter headings with no body are navigation records. Release subroutes that serve an app shell were matched to headings in the retained root release page. Four newer entries were supplemented from matching official Python/C++/Rust changelogs. The C++ changelog also supplied 0.68.1 (September 30), absent from the website navigation snapshot.

One linked upcoming C++ route (`0-69-0-upcoming`) has no matched content in the retained website/changelog. Its card is explicitly unresolved. Version-date conflicts in the website snapshot are preserved as route provenance; use the official changelog/current pinned headers before choosing a version.

Some upstream articles are placeholders or contain an unfinished-content notice. These are marked individually in the catalog and JSON. Titles alone are not treated as implementation evidence.

All documentation links discovered by this bounded sitemap/navigation traversal are inventoried. Account-only portal screens, licensed market data, general marketing/blog pages, and arbitrary external references are outside this documentation conversion. Rust, HTTP, Raw, and Data release history are indexed; implementation depth focuses on the requested Python and C++.

No credentials, authenticated data request, live session, C++ build, or hypothesis backtest was used. Validation checks document structure, Python example syntax, local links, source hashes and archive byte identity. It does not establish runtime success, exhaustive signature correctness, or sponsor entitlement.
